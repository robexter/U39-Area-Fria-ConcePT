# ÁREA FRIA CONCEPT — V5 — MATRIZ DE VALIDAÇÃO

## Abrangência
11 projetos, cada um com módulo Conteúdo Integral da V4 preservado **byte a byte** e Laboratório Concept V5 acrescentado sem alterar a versão anterior.

## Componentes implementados
- 1. Fundamentos físicos: 4 controles interdependentes e índices didáticos
- 2. Processo e tendências: caminho de correntes específico, gráfico SVG de eficiência relativa e carga hidráulica
- 3. Diagnóstico CIC: 3 perturbações específicas, hipóteses embaralhadas e justificativas
- 4. Decisões encadeadas: 4 decisões que mudam qualidade/carga/risco sintéticos; pontuação e feedback
- Link bidirecional Conteúdo Integral ↔ Laboratório

## Escopo dos modelos
As saídas são indices **adimensionais arbitrários** criados para treinamento, não previsões quantitativas do equipamento, curvas OEM, setpoints, margens reais ou diagnóstico automático. Os parâmetros foram escolhidos para mostrar tendências físicas qualitativas, não estimar limites. Para tomadas de decisão reais consultar P&ID, procedimentos vigentes e engenharia.

## Limite de teste
Teste de integração em páginas-base locais anteriores e prévias. A renderização da página pública após publicação depende de GitHub Pages, Service Worker/PWA e do usuário enviar os arquivos. Não foi realizada publicação automática.

## Integridade
Foram preservados os arquivos JS da V4 exatamente, como prefixo de todos os arquivos combinados V5. Os módulos originais do GitHub não são modificados pelo pacote até a instalação local ser executada.
